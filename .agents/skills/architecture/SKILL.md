# Architecture Development Skill

## Purpose
Guides the Lead Architect role in defining and maintaining system boundaries, data contracts, and technology choices across the VideoAutomater platform.

## Key Responsibilities
1. Preserve the **One Master Video, Multi-Destination** publishing principle.
2. Review and update `docs/DATA_CONTRACTS.md` whenever inter-module communication changes.
3. Enforce loose coupling and deterministic services over complex multi-agent frameworks.
4. Guarantee that all components operate within the free-first resource strategy.
5. Review Pull Requests across sub-systems to maintain architectural coherence.
